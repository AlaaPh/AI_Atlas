Memory ranges below are planning estimates for compatible low-bit builds, generally around 4-bit and modest context. They are not measured minima. Model files, runtime overhead, image/audio encoders, and the context cache all consume memory. GPU VRAM, system RAM, and Apple unified memory are different resources. Leave room for your operating system.

How to choose

1. Pick a model that fits your hardware. 2. Use a supported runner and quantized package. 3. Compare models on the same 10–20 real tasks: a paper summary, a factual question with sources, an equation, a coding fix, and an image or chart if relevant. Record correctness, speed, memory, and failures.

For a first graphical setup, inspect LM Studio or Jan. For a reusable local service, inspect Ollama. For maximum inference control, inspect llama.cpp. Check architecture and modality support for the specific model version.

Open research tier: prioritizes access to training resources. Other tiers: prioritize practical task capability and hardware fit among permissively licensed weights. Models under custom restricted licenses are still in the catalog, but excluded from this permissive shortlist. The image and video models are listed separately because their quality cannot be compared to language models on one scale.

Read the labels · scope, pricing, sources & video links

Open-source software
The app or framework code has an open-source license. That does not automatically make its connected models open or its API usage free.

Open weights (permissive)
Downloadable weights under licenses such as Apache-2.0 or MIT. This label does not claim that all training data, methods, and code are released.

Open model + training resources
A model with substantial published training resources. This is a practical transparency label, not a formal certification.

Restricted / source available / mixed
Custom model terms, software restrictions, branding requirements, or different licenses for community and commercial components. Read the linked license for your use.

Free + paid / paid trial
Free + paid has an ongoing free entry option, which may cover only a subset of the product. A trial is temporary. “Check pricing” means current terms were not established well enough to classify.

Local-capable
A configuration can run on your hardware. Offline use requires local models and dependencies. A desktop app using a remote model is labeled cloud-assisted.
